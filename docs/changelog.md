# 変更点

日付ごとの主な変更。細かい内容は `git log` を参照。使い方は [gui_usage.md](gui_usage.md)、インピーダンス制御で分かったことは [impedance_notes.md](impedance_notes.md)。

## 2026-11-18(2 回目の更新)
**インピーダンスを入れたままの移動・保持の不具合を直した**
- インピーダンス中は、手先の直線移動(SDK の MoveL)が**受け付けられるのに動かない**ことが分かった。インピーダンスを入れた移動は、手先の目標を IK で関節角にし、**関節移動(MoveJ)に直して送る**(経路は直線でない。確認の画面に出す)。
- 命令が受け付けられたのに腕がまったく動かなかったときは、「着きました」ではなく「腕が動きませんでした」と知らせ、インピーダンスを切る。
- 着いたあと押されてずれたら、**目標の ±0.3° の点へ交互に送って**戻し、インピーダンスを切ったあと目標へ仕上げの移動をする。
  - 目標そのものへ送り直すと、コントローラの故障 **1-26** になった(インピーダンスのずれは指令の上に乗っているので、指令の上では長さ 0 の移動になるため、と推測)。
  - 設定: `imp_return_tol_deg`(ずれと見なす角度)、`imp_return_amp_deg`(行き来の幅)。
- 「今の位置を保持」の行き来の幅に、**下限 `hold_amp_min_deg` = 0.1°** を設けた。0.001° で押すと、故障 **1-23** になった。0.3° では大丈夫だった。0.1° は未確認。

**画面**
- **紫の帯(カウントダウン)**: 手順の実行中、■ 停止 の下に、いまの段と、インピーダンスが切れるまでの残り秒数を出す。
- **⌂ 初期姿勢へ戻る**は、腕が止まり、インピーダンス・ドラッグ・手順が終わり、エラー・非常停止がないときだけ押せる。
- **エラーをリセット**のボタン(コントローラの故障をリセットし、インピーダンスが残っていれば切る)。
- RViz の**目標の球が、腕が押されると一緒に動いていた**のを直した(ツールの長さ分のずらしを、今の腕の向きではなく目標の向きで計算する)。
- 上の欄の「**終了**」が右で見切れていたのを直した(各行を別の枠にした)。
- コントローラから位置が読めなかったとき(非常停止の直後など)、0 の関節角で禁止エリアを誤検出しないようにした。
- インピーダンスタブの説明を、実機で分かったことに合わせた(軌道があるときだけ効く、k=0 では戻らない)。

## 2026-11-18(1 回目の更新)
- コントローラの**手動 / 自動モードを切り替えるボタン**。
- 移動タブ「**インピーダンスを入れて移動する**」: 開始 → 1 秒後に移動 → 着いて 5 秒後に終了。
- インピーダンスタブ「**今の位置を保持して、インピーダンス制御を確かめる**」: 今の位置のまわりで全関節を ± 少しだけ行き来させ続け、戻って 10 秒待って終了(止まったままでは効かないため)。
- 禁止エリアに、ドラッグで作った壁を 3 つ足した(z ≦ 216、y ≦ −201、y ≧ 282 mm)。
- 説明を追加: [gui_usage.md](gui_usage.md)(使い方と各項目の意味、スクリーンショット)、[impedance_notes.md](impedance_notes.md)(試しのまとめ)。

## 2026-11-17
- 禁止エリアを、**ドラッグで手先を動かして決める**: 1 点で x・y・z に平行な壁、2 点以上で囲む箱。
- 「ドラッグ」タブを追加。禁止エリアのタブでもドラッグを開始・終了できる。
- 禁止エリアのタブ: 使い方の欄、3 段の入力欄(名前 / min / max)。
- エリアを作るときは、腕を半透明にし、判定に使う点(マゼンタの球)を出す。
- 禁止エリアの色を壁の向きでそろえた(x = 赤、y = 緑、z = 青、箱 = オレンジ)。エリアごと・面の軸ごとに表示を切り替えられる。
